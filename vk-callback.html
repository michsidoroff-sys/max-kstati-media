VK ID — код авторизации

Эта страница только показывает одноразовые параметры, которые вернул VK ID. Обмен кода на токены должен выполняться на VPS, чтобы пользовательский токен был выдан с IP сервера.

Параметры авторизации пока не получены. Сначала запустите подготовку OAuth на VPS и откройте выданную им ссылку.

Авторизация подтверждена. Скопируйте три значения ниже в мастер завершения OAuth на VPS. Не отправляйте их в чат.
code
device_id
state
Важно: не публикуйте и не присылайте в чат значения code, токены или защищённые ключи.
