# VK → GitHub: автоматическая публикация

В репозитории добавлен workflow **Publish to VK**. Он публикует текстовый пост и, при наличии токена пользователя, может загрузить обложку на стену сообщества.

## 1. Секреты GitHub

Откройте:

**Settings → Secrets and variables → Actions → New repository secret**

Создайте:

- `VK_GROUP_ID` — числовой ID сообщества без минуса, `club` или `public`.
- `VK_GROUP_TOKEN` — токен сообщества с правом публикации на стене.
- `VK_USER_TOKEN` — нужен для постов с новыми изображениями, если VK отклоняет загрузку фото с токеном сообщества.

Токены никогда не добавляйте в файлы репозитория: репозиторий публичный.

## 2. Подготовка поста

1. Сохраните текст UTF-8 в папке `vk/posts/`, например `vk/posts/post-001.txt`.
2. Обложку загрузите в репозиторий, например `covers/post-001.png`.

## 3. Тест без публикации

**Actions → Publish to VK → Run workflow**

- `text_file`: путь к тексту
- `image_path`: путь к картинке или пусто
- `dry_run`: **true**

Workflow только проверит файлы и ничего не опубликует.

## 4. Реальная публикация

Запустите workflow повторно с `dry_run = false`.

После успеха в Summary будет ссылка на опубликованный пост.

## Защита от дублей

`vk_publish.py` формирует стабильный `guid` из ID сообщества, текста и изображения и передаёт его в `wall.post`. Повторный запуск того же материала защищён механизмом VK от случайной повторной публикации.

## Важное ограничение VK по изображениям

По состоянию на API 5.199 `wall.post` работает с токеном сообщества, но загрузка новой фотографии на стену через `photos.getWallUploadServer` может вернуть ошибку 27 для community token. Скрипт умеет использовать `VK_USER_TOKEN` для загрузки фотографии и `VK_GROUP_TOKEN` для самой публикации.
