# max-kstati-media
Обложки публикаций канала MAX «КСТАТИ! О ЖИЗНИ»

Ручной workflow VK не является частью штатного журнала MAX→Telegram→VK.
Не использовать его для восстановления основной очереди: согласованность с
другим репозиторием автоматически не обеспечивается. Новый PR ограничивает
исполнение веткой main, передаёт входные параметры через env без shell-инъекции
и исключает печать полных OAuth-ответов. Секреты и изображения не меняются.
